## Що зберігається в кожній папці

| Файл | Призначення |
|---|---|
| main.cpp | Код програми |
| task.md | Умова задачі |
| tests.md | Вхідні дані, очікувані та фактичні результати |
| notes.md | Що вивчив, помилки та їх виправлення |

## Як я працюю над завданням

1. Записую умову в task.md.
2. Продумую алгоритм.
3. Готую 3–5 тестів та самостійно визначаю очікувані результати.
4. Пишу код у main.cpp.
5. Зберігаю, компілюю та запускаю програму.
6. Записую результати перевірки в tests.md.
7. Додаю висновки й виправлені помилки в notes.md.
8. Позначаю завершений крок у цьому списку.
9. Роблю коміт і надсилаю зміни на GitHub.

## Компіляція та запуск

Виконую в терміналі з папки відповідного кроку:

    clang++ -std=c++17 -Wall -Wextra main.cpp -o main && ./main

Після зміни коду зберігаю файл і повторно компілюю програму.
