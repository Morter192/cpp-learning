# Мої нотатки

## Що зрозумів

- Цикл while повторює команди, поки його умова істинна.
- Умова перевіряється перед кожним повторенням.
- Якщо умова одразу хибна, тіло циклу не виконається жодного разу.
- Для відліку вгору збільшуємо лічильник:
  number = number + 1;
- Для відліку вниз зменшуємо лічильник:
  number = number - 1;
- Значення лічильника після циклу може відрізнятися від останнього
  виведеного числа. Наприклад, після виведення чисел від 1 до 5
  лічильник стає рівним 6.

## Яка помилка виникла

Написав while (n = number), і програма без кінця виводила 1.

## Чому вона виникла

Знак = присвоює значення. Перед кожним повторенням у n знову
записувалося значення number, яке дорівнювало 1.
Ненульове значення в умові сприймалося як істина.

## Як виправив

Після введення n записав number = n.
У циклі використав умову number >= 1.
Після кожного виведення зменшував number на 1.

Зберіг код, повторно скомпілював і перевірив результати.
