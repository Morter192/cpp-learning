# Вивчення C

Мої завдання з алгоритмізації мовою C17 та шість практичних доповнень зі Stanford CS107. Позначаю крок виконаним, коли програма проходить мої тести і я можу пояснити код.

## Перший запуск у VS Code на macOS

Відкриваю у VS Code папку цього курсу, потім обираю **Terminal → New Terminal**. Якщо відкрито весь репозиторій cpp-learning, спершу переходжу у папку курсу командою `cd c-learning`.

```sh
cd step01
clang -std=c17 -Wall -Wextra -Wpedantic -g main.c -o main
./main
```

Стартовий приклад виведе «Починаю вивчати C». Далі відкриваю task.md і змінюю програму за умовою. Після кожної зміни повторюю компіляцію. Якщо clang ще не встановлено, виконую `xcode-select --install` і завершую встановлення інструментів Apple.

## Як працюю над кроком

1. Читаю умову в **task.md** та записую алгоритм.
2. У **tests.md** переглядаю приклади й додаю свій крайній випадок.
3. Пишу програму у **main.c**, компілюю та запускаю для кожного тесту.
4. Записую фактичні результати в **tests.md** й одне власне спостереження в **notes.md**.
5. Оновлюю чекліст, роблю коміт і надсилаю його на GitHub.
