# Мої нотатки

Помилка: написав std::count замість std::cout.
Причина: помилився в назві засобу виведення.
Виправлення: замінив std::count на std::cout і повторно скомпілював.


Що зрозумів:
- if перевіряє умову, else виконується, коли вона хибна.
- else if дозволяє перевірити наступну умову.
- == порівнює значення, а = присвоює значення.
- && означає «і»: обидві перевірки мають бути істинними.
- || означає «або»: достатньо хоча б однієї істинної перевірки.
- Вкладений if — це перевірка всередині іншої гілки.

Виправлена помилка:
Написав std::count замість std::cout.
Виправив назву та повторно скомпілював програму.




Що закріпив:
- number % 2 == 0 перевіряє парність числа.
- || використовуємо, коли достатньо хоча б однієї істинної перевірки.
- && використовуємо, коли обидві перевірки мають бути істинними.

Виправлена помилка:
Написав else if (a * b) замість else.
Це перевіряло добуток як умову.

тому замінив її на else.
