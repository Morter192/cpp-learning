# Мої нотатки

1. Чим int відрізняється від double?
int зберігає цілі числа, а double — числа, які можуть мати дробову частину.

2. Чому в нашій формулі ділимо на 2.0, а не на 2?
Оскільки a і b мають тип int, ділення їхньої суми на 2 відкине дробову частину. Ділення на 2.0 дозволяє отримати дробовий результат.

3. Чи зміниться average автоматично, якщо після його обчислення змінити a?
Ні. Потрібно повторно обчислити значення командою:
average = (a + b) / 2.0;
Збереження й повторна компіляція потрібні після редагування коду, але не замінюють цю команду.

4. % знаходить остачу від ділення цілих чисел.
5. bool має два значення: true (істина) і false (хиба).
6. char зберігає один символ, наприклад 'A', який записуємо в одинарних лапках. Текст записуємо в подвійних: "burmalda".
7. виправив помилку: виведення false не змінювало isReady; виправив, додавши isReady = false;.
